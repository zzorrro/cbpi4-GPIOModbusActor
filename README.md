# CBPi4 GPIOModbus Actor (GPIO + Modbus RTU для частотников)

Плагин для CraftBeerPi 4, позволяющий управлять частотным преобразователем (VFD) через комбинацию GPIO-реле (команда Пуск/Стоп) и аналогового модуля RS485-to-0-10V по протоколу Modbus RTU (уставка скорости).

Этот плагин идеально подходит для управления насосами и мешалками на частотниках, обеспечивая плавный пуск/остановку и точный контроль скорости.

## 🎯 Особенности
- **Двойное управление**: GPIO-реле для команды Run/Stop + Modbus 0-10V для уставки скорости
- **Плавный пуск и остановка**: Частотник сам обеспечивает плавный разгон/торможение
- **Защита от залипания реле**: Даже если GPIO-реле физически залипнет, команда Modbus 0% остановит частотник
- **Автоматическое переподключение**: При потере связи Modbus плагин самостоятельно попытается восстановить соединение
- **Безопасность**: Автоматическое размыкание реле и сброс скорости при остановке шага или перезапуске CBPi4
- **Гибкость**: Настройка всех параметров (порт, скорость, адрес, регистр, GPIO пин) прямо из веб-интерфейса CBPi4

## 📦 Установка

### Шаг 1: Установка зависимостей и настройка прав
```bash
# Установка необходимых библиотек в окружение CBPi4
pipx runpip cbpi4 install pymodbus pyserial

# Добавление текущего пользователя в группу dialout (для доступа к COM-портам)
sudo usermod -a -G dialout $USER

# Перезагрузка системы для применения прав доступа
sudo reboot

# Установка плагина из этого репозитория
pipx runpip cbpi4 install git+https://github.com/zzorrro/cbpi4-GPIOModbusActor.git

# Перезапуск службы CBPi4
sudo systemctl restart craftbeerpi.service


ls -l /dev/ttyUSB*
