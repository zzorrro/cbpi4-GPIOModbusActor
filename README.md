# CBPi4 GPIOModbus Actor (GPIO + Modbus RTU для частотников)

Плагин для CraftBeerPi 4, позволяющий управлять частотным преобразователем (VFD) через комбинацию GPIO-реле (команда Пуск/Стоп) и аналогового модуля RS485-to-0-10V (либо прямого подключения, если частотный преобразователь поддерживает связь по RS-485) по протоколу Modbus RTU (уставка скорости).

Этот плагин подходит для управления насосами и мешалками на частотниках, обеспечивая пуск/остановку и контроль скорости.

## 🎯 Особенности
- **Двойное управление**: GPIO-реле для команды Run/Stop + Modbus 0-10V для уставки скорости
- **Плавный пуск и остановка**: Частотник сам обеспечивает плавный разгон/торможение
- **Защита от залипания реле**: Даже если GPIO-реле физически залипнет, команда Modbus 0% остановит частотник
- **Автоматическое переподключение**: При потере связи Modbus плагин самостоятельно попытается восстановить соединение
- **Безопасность**: Автоматическое размыкание реле и сброс скорости при остановке шага или перезапуске CBPi4
- **Гибкость**: Настройка всех параметров (порт, скорость, адрес, регистр, GPIO пин) прямо из веб-интерфейса CBPi4

## 📦 Установка

### Шаг 1: Установка зависимостей и настройка прав
```bash
# Установка необходимых библиотек в окружение CBPi4
pipx runpip cbpi4 install pymodbus pyserial

# Добавление текущего пользователя в группу dialout (для доступа к COM-портам)
sudo usermod -a -G dialout $USER

# Перезагрузка системы для применения прав доступа
sudo reboot

# Установка плагина из этого репозитория
pipx runpip cbpi4 install git+https://github.com/zzorrro/cbpi4-GPIOModbusActor.git

# Перезапуск службы CBPi4
sudo systemctl restart craftbeerpi.service

Проверьте, видит ли система адаптер
ls -l /dev/ttyUSB*

По умолчанию задается порт: /dev/ttyUSB0, если порт называется иначе (например, ttyUSB1), укажите его в настройках.

Если к вашей Raspberry Pi уже подключены другие USB-устройства, адаптер может получить имя `/dev/ttyUSB1` или `/dev/ttyUSB2` вместо `/dev/ttyUSB0`, а также при перезагрузке имена портов могут меняться местами.
Для правильной инициализации нужно добавить в настройки уникальное имя порта.

Узнать уникальное имя порта
ls -l /dev/serial/by-id/

Вы увидите вывод вроде этого:
lrwxrwxrwx 1 root root 13 ноя  6 21:00 usb-1a86_USB_Serial-if00-port0 -> ../../ttyUSB1

Вместо /dev/ttyUSB0 в настройках плагина CBPi4 нужно прописать полное имя из этой папки:
/dev/serial/by-id/usb-1a86_USB_Serial-if00-port0
